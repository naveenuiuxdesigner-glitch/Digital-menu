# SR Enterprises Digital Bakery Menu

A mobile-first digital bakery catalogue built with React and Vite.

## Run locally

```sh
npm install
npm run dev
```

## Features

- Searchable catalogue with 11 horizontally scrolling bakery categories
- Product availability and detail views
- Product-specific WhatsApp enquiries and click-to-call buttons
- Responsive two-column product layout for mobile screens

Update the business contact values in `src/config/business.js` before publishing.
